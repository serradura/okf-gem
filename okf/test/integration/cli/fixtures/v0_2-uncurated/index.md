# Curation faults v0.2 makes visible

Conformant and well-shaped; what is wrong here is curation, which is lint's
half of the split. Each concept carries exactly one fault so a finding can be
traced to a file by name.

* [Expired](expired.md) - past its own stale_after
* [Unattributed](unattributed.md) - a footnote no source answers
* [Unused source](unused-source.md) - a source no footnote cites
* [No actor](no-generated-by.md) - generated without a by
* [Incomplete computation](incomplete-computation.md) - the contract §10 requires
* [Still v0.1](legacy.md) - the retired spellings, both of them
* [Unprefixed](unprefixed.md) - a human sign-off that reads as a machine's
* [Both computation](both-computation.md) - the computation provided twice
