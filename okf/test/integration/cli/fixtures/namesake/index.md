# Namesake

A bundle carrying a directory literally named `root` — the word `--dir` and
`--area` accept as a spelling of the bundle root, so this is the one shape
where the alias and a real directory collide. The alias must yield: a
directory nobody can name is worse than a spelling nobody can use.

* [Charter](charter.md) - the concept that really is at the root
* [Handbook](root/handbook.md) - inside the directory named root
