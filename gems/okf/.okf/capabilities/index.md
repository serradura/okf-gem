# Capabilities

What this gem already answers, and through which surface. Read it before adding
a verb or computing anything — the point of a catalogue is that the eighteenth
verb is not the ninth verb under a new name, and that a number you are about to
derive is one the model already exposes.

`test/unit/bundle_catalog_test.rb` compares the verb catalogue against the
command registry itself, so a verb added to the code and not to the catalogue is
a red suite rather than a stale document.

* [The Verbs](verbs.md) - Every `okf` command and subcommand, what it answers, and the shared flags they all inherit.
* [The Library](library.md) - What `require "okf"` gives an embedding application, and the one surface no verb reaches.
