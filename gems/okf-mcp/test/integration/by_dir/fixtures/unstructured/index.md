# Unstructured

A bundle whose `log.md` groups its entries under `###` headings instead of the
`##` the entry split looks for. §7 calls a log "a flat list of date-grouped
entries" without fixing the level, so this is a conformant log the bound cannot
divide — and the whole point of the fixture: a file the splitter returns in one
piece must still be counted and still be bounded.
