# Prompt: consume — use a bundle as context

1. **Orient first.** `list_bundles` names every bundle this server holds and
   the slug each answers to. `dirs` gives a bundle's shape; `index` with `dir`
   opens the branch you want — its authored index body, rollups and concept
   listing — and `log` gives recent history. Then follow links only into the
   concepts the task needs, one `read_concept` at a time. For a *pointed
   question* rather than broad context, switch to the okf-search prompt's
   discipline: map → `search` → only the winning bodies. For a large bundle,
   `graph` with view `"minimal"` gives the whole link structure at once, so
   you can plan a traversal without reading a single body.
2. Treat broken links as not-yet-written knowledge, not errors.
3. **Surface what you learn.** This server never writes. If you learn
   something durable while working — a fact the bundle lacks, a link it is
   missing, a concept that no longer matches reality — say so instead of
   letting it evaporate: recording it belongs to the bundle's maintainers
   through the okf skill and CLI, and what keeps a bundle alive is being told.
