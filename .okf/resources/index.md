# The resources

`resources/` holds what someone copies *out* of this repository into a project
of their own. It is the answer to a naming question the layout takes seriously:
a top-level name is either forced by an external consumer, or it goes here.

One item so far.

* [The GitHub CI recipe](ci-github.md) - `resources/ci/github/` — a workflow that validates and lints bundles, published so it can be copied.
